# BizertIA

BizertIA is an agentic university platform that leverages multiple AI agents powered by Ollama and NVIDIA technologies to automate administrative workflows, assist students, analyze absence justifications using computer vision, and provide intelligent academic support.

## Key Features

- Student absence tracking

- AI absence justification validation

- Computer vision document verification

- Agentic workflow orchestration

- AI administrative assistant

- Student chatbot

- Course information retrieval

- Academic recommendation system

- Notification engine

## Tech Stack

- Express.js

- Python

- LangChain

- Ollama

- NVIDIA NIM

- MongoDB
